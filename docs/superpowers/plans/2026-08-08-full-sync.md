# Full Sync Implementation Plan

> **For agentic workers:** Implement task-by-task. Steps use checkbox syntax.

**Goal:** Settings Full Sync verifies ledger image UUIDs against Pixelfox and removes missing entries only (no auto-upload), with double confirmation.

**Architecture:** `PixelfoxApiClient.imageExists` → `BackupService.fullSyncRemote` mutates `BackupLedger` → Settings UI double-confirm + progress. Spec: `docs/superpowers/specs/2026-08-08-full-sync-design.md`.

**Tech Stack:** Flutter/Dart, Provider, http + FakeApiHttp, DE/EN l10n.

## Global Constraints

- No auto-upload during Full Sync
- Entries without imageUuid left alone
- Double confirmation before start
- User-facing copy via lib/l10n only
- Unit tests use fake HTTP only
- `make check` before done
